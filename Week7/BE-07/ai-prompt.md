Build a Node.js Express endpoint POST /classify-book that takes { title, price, availability } as JSON input. Validate the input with Zod, reject with 400 if title is missing. Send the data to an LLM via OpenAI SDK pointed at OpenRouter, using a prompt stored in a separate file. The model should return JSON with category (one of: fiction, non-fiction, childrens, other), summary, and confidence (0-1). Parse and validate the model's output with Zod. If validation fails, retry once by sending the model its own error, then return 422 if it still fails, and log the failure to a file instead of crashing. Add a 30 second timeout on the LLM client, retry only on timeout/429/5xx errors with exponential backoff, and add a kill switch environment variable LLM_ENABLED that returns 503 when set to false. Also log token usage and duration per call.
